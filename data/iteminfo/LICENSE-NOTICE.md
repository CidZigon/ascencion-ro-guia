# Fuente de las descripciones de objetos

La instantánea de `itemInfo.lua` proviene del proyecto de traducción
[ROenglishRE](https://github.com/llchrisll/ROenglishRE) (continuación de
[zackdreaver/ROenglishRE](https://github.com/zackdreaver/ROenglishRE)),
archivo Pre-Renewal `Translation/Pre-Renewal/SystemEN/LuaFiles514/itemInfo.lua`,
revisión `66cdfec631603fda6a90ba4bbe26ab07b5204c84` del 5 de agosto de 2026.

Los autores de esa traducción indican que el archivo puede distribuirse, usarse
y modificarse con libertad, y que no debe presentarse como parte de otro
proyecto salvo que se trate de un fork. El archivo fuente se conserva aquí sin
modificaciones; el catálogo web extrae únicamente el texto identificado
(`identifiedDescriptionName`), sin los nombres de recurso del cliente.

El texto es el del cliente en inglés. No es una traducción al español ni una
confirmación de que AscencionRO use exactamente el mismo wording.
